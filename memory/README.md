# Memoria portátil para IA

Herramienta para guardar quién eres y cómo quieres que te respondan, y llevarlo a cualquier IA (Claude, ChatGPT, Gemini…) sin repetirlo cada vez.

## Uso
1. Abre `memory/index.html` (en GitHub Pages: `/memory/`).
2. Rellena tu perfil. Se guarda en tu navegador.
3. En una IA nueva: **Copiar para pegar en una IA** → pégalo como primer mensaje.
4. Al terminar una conversación: **Copiar mensaje de actualización** → pégaselo a la IA → pega su JSON en la herramienta y pulsa **Fusionar**.
5. Haz un respaldo con **Respaldo .json** de vez en cuando.

## Privacidad
Este repositorio es público. **No subas tu `memoria.json` ni `memoria.md` aquí.** Los datos viven solo en tu navegador y en los archivos que tú descargues.
